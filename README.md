# WTC

Where to, next. A sample travel desk for flights, hotels, trains, buses, and holiday packages.

Fares, rooms, and timetables are generated in the browser. Confirming a booking stores it in this browser only. No payment is taken and no ticket is issued.

## Run locally

```bash
npm install
npm run dev
```

The app starts at http://127.0.0.1:5173.

```bash
npm test
npm run build
```

## What you can do

- Search flights (one way or round trip), compare saver, flexi, and comfort fares, and book both legs.
- Search hotels by city and pick a room type.
- Search Indian trains and buses.
- Open a holiday package and book it per person.
- Sign in with a name stored on this device, then find every confirmation under My Trips.
